# 图片色彩提取与高级渐变色生成器

纯前端独立网页工具，零依赖、零框架，原生 HTML / CSS / JavaScript 实现。

## 功能概览

- **图片色彩提取**：上传图片，通过 Median Cut + CIELAB 色彩空间算法提取 2-6 种主色调，生成美术风格色卡，支持下载 PNG
- **多色渐变编辑器**：支持 2-6 色自由混排、拖拽排序，四种渐变类型：
  - 网格 Mesh（默认，动态光斑流动）
  - 线性 Linear（0°-360° 角度可调）
  - 径向 Radial
  - 流动 Flow（背景位移动画 + 色彩淡入淡出）
- **预设渐变库**：点击小方格一键应用，自动滚动到预览区
- **CSS 复制 & 壁纸下载**：一键复制 CSS 渐变代码，下载 1920×1080 高清壁纸
- **示例色卡**：点击示例图片自动提取色卡（作者 @jojocharm）
- **双模式提取**：艳丽模式（高饱和偏好）/ 灰调模式（低饱和偏好），切换自动重提取并缓存结果

## 本地运行

因为使用了 `fetch('config.json')`，**不能直接双击 index.html 打开**（file:// 协议下 fetch 会被浏览器拦截），需要启动本地服务器：

```bash
# 方式一：Python（推荐）
python -m http.server 8080
# 然后访问 http://localhost:8080

# 方式二：Node.js
npx serve .

# 方式三：VS Code Live Server 插件
```

## 统计弹窗规则

- **计入次数的操作**：下载渐变壁纸、复制 CSS 代码、下载色卡
- **触发逻辑**：累计第 10 次首次弹窗，之后每 9 次弹一次
- **防骚扰**：同一次数不会重复弹，数据存在 localStorage
- **关闭规则**：倒计时结束后按钮才可点击，仅按钮可关闭，点遮罩层无效
- **重置**：清除浏览器 localStorage 即可重置计数

## 色彩提取算法

1. **预处理**：降采样至 200px，剔除纯白/纯黑，非低饱和图过滤 S<0.15 的灰像素
2. **Median Cut**：CIELAB 空间递归切分，生成候选色
3. **视觉加权排序**：
   - 艳丽模式：`面积 × 色度离心距² × 明度钟形曲线`，后处理饱和度 +15%
   - 灰调模式：`面积 × 低饱和偏好 × 明度钟形曲线`，后处理饱和度 -10%
4. **去重**：Lab 距离 < 18 视为重复跳过
5. **结果缓存**：同一图片的不同模式/数量结果自动缓存，切换不重复计算

## 渐变下载说明

- Mesh / Flow 动态渐变：建议先暂停再下载，画面更稳定
- 线性 / 径向：静态渐变，直接下载即可
- 下载尺寸：1920×1080（16:9）

## 技术栈

- 原生 HTML5 / CSS3 / ES6+
- Canvas API（色卡生成、壁纸下载、Mesh 离屏渲染）
- FileReader API（本地图片读取，不上传服务器）
- localStorage（计数统计、提取结果缓存）
- 零外部依赖，无 CSS 框架，无构建工具
